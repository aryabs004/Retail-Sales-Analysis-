RETAIL SALES ANALYSIS 

*Project Overview:
This project focuses on analyzing retail sales data to uncover insights into sales trends, customer behavior, and product performance. An interactive dashboard was developed using Power BI to help stakeholders make data-driven decisions.

*Objectives:
- Analyze overall sales performance
- Understand customer purchasing behavior
- Identify top-performing products and categories
- Build an interactive dashboard for business insights

*Tools & Technologies:
- Microsoft Excel – Data Cleaning & Preparation
- Power BI – Data Visualization & Dashboarding
- DAX (Data Analysis Expressions) – Calculations & Measures

*Key Skills Demonstrated:
- Data Cleaning and Transformation: I cleaned and transformed the data to prepare it for analysis.
- Data Modeling: I created a robust data model to support complex calculations and analysis.
- Data Visualization: I designed interactive visualizations using various charts, cards, and slicers to facilitate easy-to-understand insights.
- DAX Functions: I leveraged DAX functions to create calculated measures and columns that drove business insights.

*Key Features of the Dashboard
- Sales Trends: Analyzed sales trends over time to identify patterns and anomalies.
- Customer Segmentation: Segmented customers based on demographics and purchasing behavior.
- Product Performance: Evaluated product performance and identified top-selling products.
- Interactive Filters: Created slicers and filters to enable users to drill down into specific data points.

*Key Insights:
- Certain product categories consistently drive higher revenue.
- Sales show noticeable trends over specific time periods.
- A small segment of customers contributes significantly to total sales.
- Regional performance varies, indicating opportunities for targeted strategies.
